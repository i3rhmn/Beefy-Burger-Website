The Making of Beefy Burger Website

Impact of Design and Color Choices

Our design process focused on creating a consistent and appealing visual experience that embodies the fun and friendly atmosphere of Beefy Burger. We selected warm colors, primarily a shade of yellow (#ffcb05), which evokes happiness, appetite, and energy — qualities we wanted our brand to convey.

The use of neutral tones like #2c2c2c (dark grey) and #e8e8e8 (light grey) allowed us to emphasize the brand color without overwhelming the user. This combination ensures that all components of the website are readable, visually balanced, and make key elements pop.

Impact of HTML, CSS, and JS Code on Maintainability

We structured our HTML with semantic elements, such as header, nav, main, and section to ensure the content is easily understood by developers and screen readers alike. This also makes the website easier to maintain because each part of the document is clearly defined.

The CSS was written with modular classes that can be reused across different pages to maintain consistency. By using consistent class names like `.menu-item`, `.staff-member`, and `.hero`, we ensured styling is centralized and manageable. Adding or modifying styles for one component propagates across all similar components, which saves time and effort in the long run.

Using JavaScript for form validation and dynamic features helps enhance user experience while keeping the code maintainable. We used simple, easy-to-read functions that handle real-time validation feedback for users. By placing JavaScript in a separate file (`script.js`), it is easy to modify or extend the functionality without affecting the main HTML structure.
